Recommended mobile treatment

Visible above the horizontal tools

One compact key-ring row under the app header, followed by the file tools. Do not hide it, and do not leave a second “My key ring” tab in the scroller.

  • Color is not the only signal. Include explicit state text and an icon.
  • Selection is separate from key state. Use an outline for the selected destination, so green does not mean “selected.”
  • Loaded does not mean backed up. The green state says only that a key is available in this session.
  • Optional third state: if an encrypted key is saved locally but locked, show “Saved on this device · unlock” rather than implying no key exists.
